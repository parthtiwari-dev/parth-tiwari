Specimen 05 · the row becomes the hero, 620ms Interactive
Signature
Row → hero, 620ms, cubic-bezier(.16,1,.3,1). Production uses the View Transitions API with a FLIP fallback.
Reveal
A clip-path mask, never opacity plus a 20px float. 700ms, staggered 80ms. Type arrives as if printed.
Re-sort
FLIP across twelve rows, 620ms, 22ms stagger. The only other heavy moment on the site.
UI feedback
150-250ms. Anything longer needs a reason. Exit faster than enter. Never transition: all.
Worlds
Canvas, capped at 30fps, paused when off screen or when the tab is hidden. One gsap.ticker equivalent, never a second clock.
Reduced motion
Every world renders its final frame and stops. Not a shortened animation. The static frame is composed to stand on its own.
