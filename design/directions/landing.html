The gap

Most AI products die between the demo and the deploy.

The model works in a notebook. Then it needs auth, storage, a job queue that survives a GPU dying halfway through, and someone who is still answering messages in week six.

That stretch is where projects stall, and it is the part I do. Not a prototype you have to find someone else to finish. The whole thing, deployed, on a URL you can send to anyone.

BeatMind

Producers drop in a track and get its stems, key, tempo and song structure back, then rebuild it in an editor that keeps every substitution in key and in time.

The hard part was failure, not features. GPU workers die mid-job and report nothing, so the pipeline is a resumable state machine with lease tokens and fencing, and a stale worker cannot overwrite a newer attempt.

Vivid

A script becomes a shot-by-shot storyboard. A planner breaks the scene down, a diffusion model renders each shot, and the frames are scored automatically for prompt alignment and face consistency.

I trained the model it runs on. A six-stage dataset pipeline, then the LoRA itself. Conditioning each shot on the last one was meant to preserve continuity and instead overrode the prompt, so it now uses a single character anchor.

Tathya

It watches public government sources and clusters what it finds into sourced case files, showing what government, media and citizens each said about the same event.

It issues no verdict. Every claim carries its source and the reader decides. Nothing is summarised into an opinion, because the moment it does that it stops being a record.

A checkbox is not a rights check.

I shipped a self-attestation tickbox for copyright, then deleted it. Export now has to resolve a track's full lineage across two independent sources, and anything unresolvable blocks.

19 Jul 2026

I predicted forty percent. I measured eight.

A model swap that was supposed to be a large win was not, so it went back. The measurement is the useful artifact, not the hypothesis.
