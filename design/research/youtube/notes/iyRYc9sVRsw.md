## What it is

A locally-run "design operating system" he built by prompting Claude. Panels shown: Create,
Library, Studio, Insights, System. It exists because of two stated limitations of Claude Design:

> "the design can't really go anywhere. So, we can build designs, but we can't, for example,
> post that on social media or we can't send it to clients directly."

> "we're kind of waiting for them to build tools that we may want rather than building something
> that's completely unique."

## The three levels

**Level 1: own your design system outside Claude Design.** The only genuinely useful line:

> "I recommend that you do this cuz **you always want to have sovereignty and own your own
> design systems.**"

Export path, again: Claude Design, open the design system, Share, Project HTML, Project archive,
Export. The archive is portable to Claude, ChatGPT, or anything else.

Prompt to register it locally:
> Hey there, I would like the ability to find any design OS on my computer, add it to my design
> operating system, and allow me to build things with Claude inside this operating system.

**Level 2: run the same design system through any model.** Named: OpenAI, Gemini, Claude, "GLM
5.3", "GPT 5.6". He references an "AI model design benchmark" leaderboard on screen but does not
name it. Point made: if you exhaust Claude credits, an exported `design.md` still works
elsewhere.

**Level 3: automated publishing.** Uses **Blotato** (spoken "Blutato", https://blotato.com,
inferred) to post generated carousels to Instagram, LinkedIn, Facebook and Pinterest from inside
the OS. Setup: Blotato dashboard, Settings, connect accounts, then API dashboard, "set up API /
MCP", copy the key, hand it to Claude.
