# Phase 5 BeatMind storyboard lock

Locked 2026-09-01 for production implementation. This document records the approved
storyboard translation before the Astro world route is built.

## Selected treatment

**Precision Descent** uses one persistent machine and a native vertical camera journey.
The source specimen stays attached to one clock as it becomes five stems, receives real
analysis, becomes an arrangement and resolves into a mixdown representation. It was
selected because the causal story survives close phone crops without captured horizontal
scrolling.

The two alternatives remain visible in
`design/directions/phase-5-beatmind-storyboard.html`:

- **Foundry Conveyor** was rejected because a lateral production line weakens the phone
  composition and encourages scroll capture.
- **Signal Autopsy** was rejected because it loses too much of the immersive machinery and
  reads as an evidence diagram rather than a project world.

The production machinery plate is
`design/references/beatmind-precision-descent-machinery.png`. It is decorative only. It
contains empty rails and chambers, with no generated waveform, UI, copy, number or product
claim. All signals placed over it must resolve to the sanitized BeatMind export.

## Scene contract

1. Specimen chamber: one complete source waveform enters.
2. Separation gantry: the source becomes vocals, backing vocals, drums, bass and other.
3. Worker failure: conditional on an explicitly correlated real trace.
4. Retry: conditional on the same verified trace.
5. Analysis scanner: real sections, downbeats and permitted analysis labels appear.
6. Arrangement deck: the five lanes become a readable section arrangement.
7. Mix chamber: shared-scale envelopes remain visible while the lanes converge.
8. Render press: the five lanes resolve into one mixdown representation.
9. Measurement and boundary: verified context, denominators, limits, audio status and any
   omitted trace are stated.
10. Deep-dive handoff: one action opens `/work/beatmind/`.

If the export has no proven lifecycle correlation, scenes 3 and 4 are not rendered and the
world becomes a coherent eight-scene sequence including measurement and handoff. The final
boundary states that no publishable retry trace is visualized.

## Production boundaries

- One normal vertical document scroll is the only required input.
- Machinery is decorative; exported BeatMind data owns every signal.
- Audio starts as `withheld`, with no URL, media element or disabled fake control.
- There is no runtime data request, trapped scroll or invented fallback signal.
- Reduced motion, no JavaScript and missing Canvas2D show the same composed final frame and
  complete DOM narration.
- Phone uses close camera crops and reduced machinery rather than a scaled desktop stage.
