The first version put too much trust in a plausible generated answer. That is not enough
when the system speaks in my name.

Evidence checks now happen before drafting, and the completed packet waits in a review
queue. Human review is not a short pause inside one process. It is a stored state that can
survive a restart and remain unresolved for as long as necessary.
